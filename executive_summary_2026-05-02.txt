PROJECT OVERVIEW
----------------
SenseEase is an NPU-powered visual comfort system designed for HP AI PCs. It
intercepts optical flow at the hardware rendering layer to prevent two closely
related medical conditions:

  - Visually Induced Motion Sickness (VIMS): affects ~14.8% of display users;
    caused by a sensory conflict between the visual cortex (detects motion) and
    the vestibular system (registers stillness), producing nausea.

  - Digital Eye Strain (DES): affects ~80% of office workers; caused by
    unmanaged luminance transitions, high-contrast window switching, and
    prolonged high-frequency flicker exposure.

The system targets 97.6% of display users experiencing some form of visual
discomfort, with a specific clinical path for the 2.8% with diagnosed
vestibular disorders.


FOUR-LAYER ENGINEERING ARCHITECTURE
-------------------------------------
  Layer 1 — Sensing:
    HP Look to Move gaze vectors, mouse/keyboard/touchpad event streams, and
    DOM scroll velocity are fused to compute Optical Flow Intensity (OFI).
    Camera optional; gaze and ambient-lux processing run fully on-device via
    Google MediaPipe FaceLandmarker and the AmbientLightSensor API, so no
    frame data ever leaves the machine.

  Layer 2 — Inference:
    An ALSTM-FCN model maintains a rolling VIMS Pressure Index. Efference Copy
    weighting distinguishes user intent: 0.2x in Driver Mode (user-initiated
    motion) vs. 1.5x in Passenger Mode (passive scrolling/video).

  Layer 3 — Rendering:
    A WebGL DitheringShader applies a pixel-level FOV mask when pressure
    exceeds threshold. The Chang-Hain Stationary Anchor — a white grid locked
    to screen coordinates — resists destabilizing optical flow. A CSS fallback
    guarantees graceful degradation.

  Layer 4 — Feedback:
    An HP IQ Chatbot collects real-time user complaints. A Habituation
    Scheduler relaxes protection at 1%/sec after 120 seconds of symptom
    silence, modeling adaptive brain plasticity.


WHAT HAS BEEN ACCOMPLISHED
---------------------------
  Frontend & Application:
    - Full single-page application (SPA) built in HTML/Tailwind CSS/JavaScript
      with Vite as the build toolchain.
    - Four main tabs: Project Overview, Live Demos, Statistics Dashboard,
      Meet the Team.
    - Theater Mode and Auto-Demo Mode for presentation contexts.
    - Sticky real-time dashboard strip showing NPU Load, Optical Flow,
      VIMS Pressure, and GPU Render metrics.

  Core JavaScript Modules (src/core/):
    - EyeTracker.js — gaze and input event sensing
    - DataNormalizer.js — OFI normalization pipeline
    - VIMSPredictor.js — ALSTM-FCN pressure index logic
    - SenseObserver.js — central event bus
    - InferenceEngine.js — Efference Copy weighting
    - RenderController.js — FOV mask orchestration
    - DitheringShader.js — WebGL shader with GPU-safe rand() precision
      (mod(dt, PI) fix for production GPU driver compatibility)

  UI Components:
    - ChatbotUI.js — HP IQ Feedback chatbot with adaptation reset trigger

  Five Interactive Demo Scenarios:
    1. Extreme VIMS — Passenger Mode skydiving video with live FOV mask and
       Chang-Hain anchor grid. NPU intercept latency demonstrated < 150ms.
    2. Live Trading Terminal — Driver Mode stock ticker with peripheral zone
       auto-dropped to 5 Hz with blur on hover, focal target kept at 60 fps.
    3. DES Document Multitasking — IDE/spreadsheet window switching with
       500ms non-linear brightness/contrast transition; optional webcam ambient
       lux sensing.
    4. Prolonged Office Work — 1-hour time-lapse with circadian colour
       temperature automation from 6500K (morning) to 2700K (evening) and
       screen flicker suppression overlay.
    5. Progressive Habituation (Chang-Hain Framework) — Graded vestibular
       rehabilitation: FOV clear zone expands from 15% to 115% in 2-second
       cycles; "I feel dizzy" HP IQ trigger resets adaptation.

  Statistics Dashboard:
    - Real-time Chart.js graphs for VIMS Interception Monitor and DES Fatigue
      Reduction (with vs. without SenseEase comparison).
    - Session summary: FOV Intercepts, Peak Optical Flow, Peak VIMS Pressure,
      Session Uptime.

  Key Performance Claims Embedded in Demo:
    - VIMS Reduction:          67%
    - DES Score Drop (VAS):   -2.3 pts
    - NPU Intercept Latency:   < 150 ms
    - Efference Copy Accuracy: 88.4%


WHAT CAN BE SUCCESSFULLY DEMONSTRATED TODAY
--------------------------------------------
  The following flows are fully functional in a browser:

  1. Open index.html (served via Vite) — the full SPA loads with navigation,
     hero section, and architecture overview.

  2. Live Demos tab → Scenario 1: Play the skydiving video, toggle
     "NPU Protection: ON", observe the WebGL FOV mask and Chang-Hain grid
     overlay activate in real time. Switch to Auto-Demo Mode for a hands-free
     walkthrough.

  3. Live Demos tab → Scenario 2: Interact with the live stock trading
     terminal; hover rows to trigger peripheral blur at reduced refresh rate.

  4. Live Demos tab → Scenario 3: Click "Switch Window Focus" to toggle
     between the dark IDE and bright spreadsheet with animated transitions;
     change room ambient lighting.

  5. Live Demos tab → Scenario 4: Play the office time-lapse; observe the
     circadian progress bar advance and the overlay colour temperature shift
     from cool to warm automatically.

  6. Live Demos tab → Scenario 5: Watch the habituation progress bar expand;
     open HP IQ Chatbot and submit a dizziness complaint to trigger an
     Adaptation Reset.

  7. Statistics tab: Real-time charts update live as demo scenarios run.
