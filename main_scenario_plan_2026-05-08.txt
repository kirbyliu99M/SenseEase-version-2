GOALS
-----
1. Hide all five existing demo sub-tabs (S1–S5) from the user-facing UI.
2. Build a single unified "Main Scenario" that fuses S1 (VIMS motion video) +
   S5 (Progressive Habituation) on a shared video base.
3. Add optional webcam-driven gaze tracking via Google's MediaPipe
   FaceLandmarker, replacing the mouse-as-gaze stub.
4. Integrate the new Main Scenario with the existing statistics dashboard
   (VIMS + DES charts) end-to-end.
5. Absorb Scenario 4's environment-light syncing into the Main Scenario; ditch
   the standalone S4 panel.


LOCKED ARCHITECTURE DECISIONS
------------------------------
- Single shared getUserMedia stream, opened only when user toggles
  "Webcam Mode" ON (lazy initialization).
  - Gaze consumer: MediaPipe FaceLandmarker (dynamic-imported on toggle).
  - Lux consumer: prefers AmbientLightSensor API when supported & permitted,
    falls back to canvas frame luminance sampling.
- Chang-Hain shader (DitheringShader.js) is NOT modified. All UX smoothing
  happens above the shader (lerp constants, gaze low-pass, calibration UI).
  The smoothstep boundary, white anchor grid, color progression, and three-
  zone semantics stay intact.
- Camera is opt-in, processed on-device. Privacy claim softens accordingly;
  default mode remains mouse + simulated circadian so the no-camera fallback
  still works fully.
- Calibration UX: option (c) — quick auto-flow at first webcam toggle
  (1.5s × 3 corner dots, ~5s total) PLUS a persistent "Recalibrate Gaze"
  button always available for booth presenters.

PHASE 5A — GAZE TRACKER  (most complex new code)
------------------------------------------------
New file: src/core/GazeTracker.js
- Dynamic import('@mediapipe/tasks-vision') triggered only when user toggles
  webcam mode ON (lazy load avoids 3–5MB upfront cost).
- Calibration micro-flow:
    1. First webcam toggle automatically launches calibration.
    2. Animated dot moves to top-left → top-right → bottom-right corners.
    3. ~1.5 seconds per corner; user looks at the dot.
    4. Iris vector recorded at each corner; affine map solved (2D linear
       solve, 3 unknowns per axis).
    5. Total ~5 seconds.
    6. "Recalibrate Gaze" button always visible in webcam mode for repeat
       calibrations (booth presenter use case).
- Output: gazeX, gazeY in screen coordinates.
- Integration: single-line patch into EyeTracker.js line 8 — replace the
  mouse-as-gaze stub with iris-derived coordinates. Downstream
  (RenderController._smoothedGazeX/Y, already at 0.2 lerp) provides
  natural low-pass smoothing — no additional filter needed.


PHASE 5B — LUX SENSOR
---------------------
New file: src/core/LuxSensor.js
- Preferred path: new AmbientLightSensor({frequency: 2}) when:
    'AmbientLightSensor' in window  AND
    secure context (https or localhost)  AND
    permission granted
  Output: lux (e.g., 0–10000) → warmth value [0,1].
- Fallback path: every 500 ms, draw the WebcamSource video frame to a
  32×32 OffscreenCanvas, sample pixels, compute average Rec.709 luminance:
    Y = 0.2126·R + 0.7152·G + 0.0722·B
  Normalize → invert (bright room = cool overlay, dim room = warm overlay)
  → warmth value [0,1].
- Calls setCircadianWarmth(warmth) at 2 Hz.
- Receiving end applies a 3-second smooth lerp.


KNOWN RISKS & MITIGATIONS
-------------------------
- MediaPipe bundle (~3–5MB WASM):
    Mitigation: dynamic import on toggle only; no impact on initial bundle.
- AmbientLightSensor is Chrome-only, behind a flag on some platforms:
    Mitigation: webcam fallback is the default; sensor is the upgrade.
- Single getUserMedia prompt asks for camera even when only lux is needed:
    Mitigation: one-line explainer above the toggle ("Camera enables gaze
    + ambient light detection. All processing is on-device.").
- Calibration accuracy degrades with glasses, dim rooms, side lighting:
    Mitigation: mouse mode remains the primary; webcam is the "Demo
    Calibrated Gaze" power option. Recalibrate button supports retries.

FEASIBILITY: Medium-high. The MediaPipe gaze path is the most complex
new code in the project. Everything else is glue.
